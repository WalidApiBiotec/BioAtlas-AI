# BioAtlas AI — Enhanced Front-End Prototype

## Folder structure

- `index.html` — page structure/content
- `css/style.css` — all visual styling
- `js/app.js` — interactions and behavior
- `assets/logo.png` — embedded logo extracted from the original HTML
- `assets/specimen.jpg` — specimen image extracted from the original HTML

## Open locally

Open `index.html` in a browser. No build step is required.

## Important

The search and AI identification features are still front-end demos. The AI result intentionally uses a small demo dataset and random selection. Replace that section with a real API call when the backend/model is ready.
